# 月度排课系统 - 开发文档

## 1. 项目概述

### 1.1 项目简介
月度排课系统是一个基于纯前端（HTML + CSS + JavaScript）的课程安排工具，核心功能是根据师资空闲时间表和课程体系表，自动生成满足约束条件的月度课程日历。

### 1.2 技术栈
- **框架**: 原生 HTML5 + CSS3 + JavaScript（ES6+）
- **Excel解析**: SheetJS (xlsx) CDN 库
- **样式**: CSS 变量 + Flexbox 布局
- **无后端**: 纯前端实现，数据仅在浏览器内存中存储

### 1.3 项目结构
```
field-demo/
├── index.html          # 主文件（包含所有HTML、CSS、JS逻辑）
├── 开发文档.md          # 本文档
└── src/                # 原始TypeScript源码（已被index.html替代）
    ├── index.ts
    ├── utils/
    │   ├── dateUtils.ts
    │   └── schedulingAlgorithm.ts
    └── data/
        └── mockData.ts
```

| 功能模块 | 描述 |

### 2.2 排课约束条件

#### 硬约束（必须满足）
1. **空闲时间**: 课程时间必须在师资的空闲时间内
2. **师资课程间隔**: 同一师资的课程之间必须保持最小间隔（≥5分钟）
3. **班级课程间隔**: 同一班级的课程之间必须保持最小间隔（≥5分钟）
4. **时间顺序递增**: 课程按课程体系表中的顺序依次排课，后一个课程的开始时间必须晚于前一个课程

#### 软约束（建议满足）
1. **课程间隔**: 两门课程之间建议保持 10 分钟间隔（无法满足时回退到 5 分钟）
2. **课程分散**: 按空闲天数与课程数量的比值间隔排课（详见分散策略）
3. **时间优先级**: 优先选择晚上时间段（18:00-22:00），其中19:00为最优时间点

#### 优化目标（可选）
1. **排课覆盖率**: 尽量将所有课程排入，无法排课的在表中标记为「✗ 无空闲时间」

#### 约束回退机制
```
第一级: 建议间隔 10 分钟（师资）
  ↓ 若无法排课
第二级: 最低间隔 5 分钟（师资）
  ↓ 仍无法排课
标记为「无空闲时间」

注意: 班级间隔始终为 5 分钟，无回退
```

### 2.3 课程分散策略

#### 策略算法
```
1. 统计每个师资的空闲天数（去重、排序）
2. 生成多种分散方案
3. 使用分散度评价函数对每个方案打分
4. 选择评分最高的方案进行排课
```

#### 分散度评价函数
```javascript
function calculateDispersionScore(dates, availableDates) {
  // 计算课期间的日期间隔
  const gaps = [gap1, gap2, ..., gapN-1];

  // 1. 覆盖范围评分：课程覆盖整个时间段的程度
  //    coverage = (最后一个索引 - 第一个索引) / (总长度 - 1)
  const coverage = (lastIdx - firstIdx) / totalRange;
  const coverageScore = coverage * 100;  // 权重最高

  // 2. 均匀度评分：间隔标准差越小越好
  const uniformityScore = 1 / (1 + stdDev);

  // 3. 最小间隔评分：最小间隔越大越好
  const minGapScore = minGap;

  // 4. 平衡性评分：最大间隔与最小间隔差距越小越好
  const balanceScore = 1 / (1 + gapRange);

  // 综合评分（覆盖范围权重最高）
  return coverageScore + uniformityScore * 50 + minGapScore * 5 + balanceScore * 20;
}
```

**评分指标说明**：

| 指标 | 权重 | 说明 |
|------|------|------|
| 覆盖范围 | 100 | 课程是否覆盖整个时间段，越全面越好 |
| 均匀度 | 50 | 间隔标准差越小，评分越高 |
| 平衡性 | 20 | 最大间隔与最小间隔差距越小，评分越高 |
| 最小间隔 | 5 | 最小间隔越大，评分越高 |

#### 分散方案生成
```
generateDispersionPlans() 生成多种方案:

1. 线性分布方案: linear-spread
   - 使用线性插值在整个时间范围内均匀分布
   - 计算公式: idx = Math.round(i / (n-1) * (total-1))
   - 确保课程覆盖从第一个到最后一个空闲天
   - 示例(20天8课): 索引 0, 3, 5, 8, 10, 13, 15, 19

2. 均匀分布方案: linear-even
   - 课程均匀分布在各段中间位置
   - 计算公式: idx = Math.floor((i+0.5) / n * total)
   - 示例(20天8课): 索引 1, 3, 6, 8, 11, 13, 16, 18

3. 尾部分布方案: end-spread
   - 课程从尾部开始反向分布
   - 确保最后一周有课程

4. 回填方案: backfill
   - 在基础间隔上增加偏移，填充整个时间段
   - 计算公式: idx = i + backInterval * i
   - backInterval = ceil((total - n) / (n - 1))

5. 偏移方案: offset-0, offset-1, ..., offset-(interval-1)
   - 在固定间隔基础上添加不同偏移量

6. 间隔方案: interval-(base-2), ..., interval-(base+2)
   - 尝试不同的间隔天数
```

#### 实现步骤
```
1. 按师资分组课程
2. 统计每个师资的空闲天数列表
3. 生成多种分散方案
4. 对每个方案计算分散度评分
5. 选择评分最高的方案
6. 按选中的日期逐个排课
   - 在目标日期的空闲时间段内查找可用时间槽
   - 检查师资冲突和班级冲突
   - 若目标日期无可用时间，尝试其他空闲日期
```

#### 时间顺序递增说明
```
约束范围: 按师资独立追踪（每个师资的课程顺序独立递增）

课程体系表顺序: 高数1(窦峥) → 高数2(窦峥) → 英语1(方浩) → 高数3(窦峥)

排课结果必须满足:
  高数1的开始时间 < 高数2的开始时间 < 高数3的开始时间（同师资）
  英语1不受高数课程时间约束（不同师资）

实现机制:
  按师资分组后，每个师资的课程依次按分散策略排课
  课程索引决定目标日期，自动保证顺序递增
```

#### 时间优先级评分
```javascript
function calculateTimePriorityScore(slotStartMinutes) {
  // 同一天时间段优先级排序：晚上 > 下午 > 上午
  
  // 晚上时间段（18:00-22:00）优先级最高
  // 19:00为最优时间点
  const EVENING_START = 18:00; // 1080分钟
  const EVENING_END = 22:00;   // 1320分钟
  const OPTIMAL_EVENING = 19:00; // 1140分钟
  const AFTERNOON_START = 13:00; // 780分钟
  const MORNING_END = 12:00;    // 720分钟

  if (slotStartMinutes >= EVENING_START && slotStartMinutes <= EVENING_END) {
    // 晚上：150-200分，19:00最优
    const distance = Math.abs(slotStartMinutes - OPTIMAL_EVENING);
    return 200 - (distance / 60) * 50;
    // 19:00 → 200分（最优）
    // 18:00或22:00 → 150分
  }

  if (slotStartMinutes >= AFTERNOON_START && slotStartMinutes < EVENING_START) {
    // 下午：100-150分，越接近18:00越高
    const progress = (slotStartMinutes - 13:00) / (18:00 - 13:00);
    return 100 + progress * 50;
    // 13:00 → 100分
    // 18:00前 → 150分
  }

  if (slotStartMinutes >= MORNING_END && slotStartMinutes < AFTERNOON_START) {
    // 中午：90分
    return 90;
  }

  if (slotStartMinutes >= 8:00 && slotStartMinutes < MORNING_END) {
    // 上午：50-90分，越接近12:00越高
    const progress = (slotStartMinutes - 8:00) / (12:00 - 8:00);
    return 50 + progress * 40;
    // 8:00 → 50分
    // 12:00前 → 90分
  }

  // 其他时间：较低分
  return 20-30;
}
```

**评分说明**:
| 时间段 | 评分范围 | 优先级 | 说明 |
|--------|---------|--------|------|
| 19:00 | 200 | 最高 | 最优时间点 |
| 18:00-19:00 | 150-200 | 晚上 | 越接近19:00分数越高 |
| 19:00-22:00 | 200-150 | 晚上 | 越接近19:00分数越高 |
| 13:00-18:00 | 100-150 | 下午 | 越接近18:00分数越高 |
| 12:00-13:00 | 90 | 中午 | 固定分 |
| 08:00-12:00 | 50-90 | 上午 | 越接近12:00分数越高 |
| 00:00-08:00 | 20 | 凌晨 | 最低 |
| 22:00-24:00 | 30 | 深夜 | 较低 |

#### 日期优先级（分散策略）
```javascript
// 分散策略优先选择有晚上时间的日期
// 采用两级优先级策略：先尝试晚上时间，不行再用所有空闲时间

function findBestDispersionPlan(availableDates, totalCourses, teacher) {
  // 1. 计算每个日期的优先级
  const datePriorityMap = {};
  for (const date of availableDates) {
    const dateAvailabilities = 获取该日期的空闲时间;
    const maxScore = calculateDatePriorityScore(dateAvailabilities);
    if (maxScore >= 150) {
      datePriorityMap[date] = 'evening';     // 有晚上时间
    } else if (maxScore >= 100) {
      datePriorityMap[date] = 'afternoon';  // 只有下午时间
    } else {
      datePriorityMap[date] = 'morning';    // 只有上午时间
    }
  }

  // 2. 生成两级方案
  const eveningDates = 过滤有晚上时间的日期;
  
  if (eveningDates.length >= totalCourses) {
    // 第一级：只用晚上时间排课
    primaryPlan = 生成晚上时间分散方案;
  }
  
  // 第二级：用所有空闲时间排课（作为回退）
  secondaryPlan = 生成所有空闲时间分散方案;

  return {
    primary: primaryPlan,      // 优先方案（晚上时间）
    secondary: secondaryPlan,  // 回退方案（所有空闲时间）
    hasEveningPriority: !!primaryPlan
  };
}
```

**两级排课流程**:
```
课程1 → 尝试 primaryPlan (晚上时间) → 成功? → 是：排课完成
                                   ↓ 否
                              尝试 secondaryPlan (所有空闲时间) → 成功? → 是：排课完成
                                                                   ↓ 否
                                                              标记为"无空闲时间"
```

**日期选择策略**:
| 条件 | 第一级策略 | 第二级策略 |
|------|-----------|-----------|
| 晚上天数 ≥ 课程数 | 优先在晚上时间分散排课 | 所有空闲时间分散排课 |
| 晚上天数 < 课程数 | 尝试晚上时间（可能排不完） | 晚上+下午+上午分散排课 |
| 只有上午时间 | 无法使用第一级 | 在上午时间中分散排课 |

### 4.3 冲突检测算法

#### 师资冲突检测
```
新课程时间段: [slotStart, slotEnd]
同师资已有课程: [eStart, eEnd]
最小间隔: gapMinutes（建议10分钟，最低5分钟）

无冲突条件（满足任一）:
  slotEnd + gapMinutes <= eStart    // 新课程在已有课程之前
  slotStart - gapMinutes >= eEnd    // 新课程在已有课程之后
```

#### 班级冲突检测
```
新课程时间段: [slotStart, slotEnd]
同班级已有课程: [eStart, eEnd]
最小间隔: CLASS_MIN_GAP（固定5分钟）

无冲突条件（满足任一）:
  slotEnd + CLASS_MIN_GAP <= eStart    // 新课程在已有课程之前
  slotStart - CLASS_MIN_GAP >= eEnd    // 新课程在已有课程之后
```

#### 冲突检测流程
```
新时间槽 → 检查师资冲突 → 检查班级冲突 → 通过/拒绝
```

### 6.3 Excel 时间处理

系统自动处理 Excel 中两种时间格式：

1. **时间字符串**: 直接解析 "09:30" → 9:30
2. **小数形式**: 0.375 = 37.5% 天 → 09:00 (24h × 0.375)

```javascript
function formatExcelTime(excelTime) {
  if (typeof excelTime === 'number') {
    const hours = Math.floor(excelTime * 24);
    const minutes = Math.floor((excelTime * 24 - hours) * 60);
    return `${String(hours).padStart(2, '0')}:${String(minutes).padStart(2, '0')}`;
  }
  // 处理字符串格式
}
```

## 10. 约束与限制

### 10.1 当前限制
- 数据仅存储在浏览器内存中，刷新后丢失
- 不支持多教师联合排课优化
- 不考虑课程先后依赖关系
- 排课仅覆盖当前显示月份

### 10.2 性能说明
- 当课程数量 > 50 门时，排课算法耗时可能较长
- 以5分钟为步长搜索，对于较长时间段效率较高
- DOM渲染支持 6×7 = 42 个日历单元格
